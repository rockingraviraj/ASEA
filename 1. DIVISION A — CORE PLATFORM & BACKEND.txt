2. Backend architecture

I recommend modular monolith first, not microservices.

This is extremely important for three people.

Don't start with:

10 Spring Boot microservices

Instead:

                    ASEA Backend
                         │
              Spring Boot Application
                         │
       ┌─────────────────┼─────────────────┐
       │                 │                 │
       ▼                 ▼                 ▼
   Control           Evidence          Integration
   Modules           Modules           Modules

Internally:

com.asea
│
├── task
├── orchestration
├── state
├── policy
├── permission
├── retry
├── budget
├── human
├── audit
├── evidence
├── repository
├── agent
├── tool
├── model
└── integration

Later, if required:

Modular Monolith
      ↓
Extract specific modules
      ↓
Microservices

This avoids premature distributed-system complexity.

Don't introduce a separate vector database.

5. Redis

Use Redis for:

Cache
Session data
Rate limiting
Temporary state
Distributed locks
Streams

And:

Redis Streams

for asynchronous agent/work execution.

Example:

asea.task.created
asea.agent.execute
asea.validation.started
asea.validation.completed
asea.task.failed
asea.human.approval
